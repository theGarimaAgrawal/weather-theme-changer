# 🌤️ Weather-Based Theme Switcher

A simple yet elegant project that dynamically changes a website’s color theme based on real-time weather conditions using the [WeatherAPI](https://www.weatherapi.com/).

---

### 📌 Features

✅ **Live Weather Integration**  
Fetches up-to-date weather data for any location (default: Shanghai) via WeatherAPI.

🎨 **Dynamic Theming**  
Applies visually distinct themes to the site depending on the current weather — including sunny, overcast, rainy, misty, and more.

💫 **Smooth Visual Transitions**  
Includes seamless color and text transitions for a polished, user-friendly experience.

🌐 **Modular & Extendable**  
Easily add new weather conditions, styles, or locations.
